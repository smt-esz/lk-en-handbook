    Useful phrases for writing

    At a glance
    Purpose Find the phrase for the job you need done in a sentence
    Structure One table per function. Left column neutral, right column more formal or more careful
    Register & voice Everything here works in essays, comments, analyses and mediations. Check before using it in an informal email
    Length Two or three connectives per paragraph is plenty
    Watch out Range is marked. Vary your connectives, and never open three paragraphs in a row the same way

    Phrases are tools, not filler. A connective that does not describe a real relationship between two ideas costs marks under text organization, see Paragraph structure and cohesion.

    Opening a text

    Naming the topic Framing the question
    • This essay discusses …
    • This text deals with …
    • The following will look at …
    • The subject of this comment is …
    • The question of whether … has been widely debated.
    • The issue at the heart of this text is …
    • Few topics divide opinion as sharply as …
    • Recent debate has centred on the question of …

    Announcing your line of thought

    Straightforward More formal
    • In the following, I will examine …
    • I will first look at …, then …
    • This text argues that …
    • This essay sets out to demonstrate that …
    • The following analysis proceeds in three steps.
    • It will be argued that …

    Adding and sequencing

    Adding a point Ordering points
    • Furthermore, …
    • Moreover, …
    • In addition, …
    • What is more, …
    • Another important point is …
    • Equally important is …
    • Apart from that, …
    • First … / Second … / Finally, …
    • To begin with, …
    • The next point to consider is …
    • More importantly, …
    • Most significantly of all, …
    • Last but by no means least, …

    Not interchangeable

    Furthermore adds weight to the same line of argument. Another point is opens a new one. Markers notice when a connective claims a relationship that the sentences do not have.

    Contrasting and qualifying

    Full contrast Partial contrast
    • However, …
    • By contrast, …
    • On the other hand, …
    • Conversely, …
    • Whereas … / While …
    • Unlike …, …
    • Nevertheless, …
    • Nonetheless, …
    • Despite this, …
    • Then again, …
    • That said, …
    • At the same time, …

    Conceding a point before you answer it

    Conceding Turning back
    • Admittedly, …
    • It is true that …
    • Granted, …
    • There is no denying that …
    • Critics rightly point out that …
    • … , but this overlooks …
    • This argument does not hold, however, because …
    • What this misses is …
    • Even so, …
    • This objection loses much of its force once …

    Concession is the cheapest way to show you have thought about the other side. Pair it every time: concede, then turn.

    Giving examples and evidence

    Introducing an example Pointing to the text
    • For example, … / For instance, …
    • … , such as …
    • A case in point is …
    • To illustrate this, …
    • Take … as an example.
    • This can be seen in line 12, where …
    • The author makes this explicit when they write, "…" (l. 7).
    • … illustrates this when …
    • The phrase "…" (l. 23) shows that …
    • This is borne out by …

    Cause, effect and inference

    Cause and effect Drawing a conclusion from evidence
    • Therefore, … / Thus, …
    • As a result, …
    • Consequently, …
    • This leads to … / This results in …
    • For that reason, …
    • … , which is why …
    • This shows that …
    • It can be seen that …
    • This suggests that …
    • The implication is that …
    • From this it follows that …
    • This creates the impression that …

    Analysis needs the right column

    Therefore links two facts. This suggests that links a fact to your reading of it. In an analysis you almost always want the second kind, because that is where the effect on the reader is described.

    Describing an author's moves

    Neutral reporting Sharper reporting
    • The author states / explains / describes that …
    • According to the author, …
    • The text points out that …
    • … goes on to say that …
    • The author argues / claims / maintains that …
    • … emphasizes / stresses / underlines …
    • … criticizes / dismisses / rejects …
    • … concedes / admits that …
    • … warns against …
    • … appeals to the reader's sense of …

    Reporting verbs carry judgement. States is neutral, claims signals doubt, concedes signals a retreat. Choosing well is a lexis mark.

    Describing structure and technique

    Structure Effect on the reader
    • The text falls into three parts.
    • The opening paragraph establishes …
    • The argument builds towards …
    • The turning point comes when …
    • The final paragraph returns to …
    • This draws the reader into …
    • The effect is to make the reader feel …
    • This lends the argument an air of …
    • The repetition drives home …
    • By addressing the reader directly, the author creates …

    Expressing an opinion

    Direct Measured
    • In my opinion, … / In my view, …
    • I am convinced that …
    • I would argue that …
    • To my mind, …
    • From my point of view, …
    • It seems to me that …
    • I would tend to agree that …
    • There is much to be said for …
    • On balance, I find … more convincing.
    • While I see the appeal of …, I would still …

    Degrees of certainty

    Confident Careful
    • Clearly, … / Undoubtedly, …
    • There can be little doubt that …
    • It is evident that …
    • … is bound to …
    • It is likely / unlikely that …
    • … may / might / could …
    • … appears to / seems to …
    • Arguably, …
    • To some extent, …
    • This would suggest that …

    Hedging is not weakness. Overstating a claim you cannot support costs more than stating it carefully.

    Agreeing and disagreeing with a position

    Agreeing Disagreeing
    • I share the view that …
    • There is a strong case for …
    • This argument is convincing because …
    • The author is right to point out that …
    • I find this argument unconvincing because …
    • This overlooks the fact that …
    • The evidence points the other way: …
    • This holds only if …, which is not the case here.

    Comparing and evaluating

    Comparing Weighing up
    • Both texts deal with …
    • Similarly, … / Likewise, …
    • … , whereas the second text …
    • The two differ mainly in …
    • Compared with …, …
    • The main advantage of … is …
    • The obvious drawback is …
    • This outweighs …
    • The strongest argument in favour is …
    • Weighing the two, …

    Referring back and moving on

    Referring back Moving on
    • As mentioned above, …
    • As shown earlier, …
    • Returning to …, …
    • This brings us back to …
    • Turning now to …
    • This raises the question of …
    • A second aspect worth considering is …
    • With this in mind, …

    Closing a text

    Summing up Leaving the reader with something
    • In conclusion, …
    • To conclude, …
    • To sum up, …
    • In summary, …
    • All things considered, …
    • On balance, …
    • Whether … remains to be seen.
    • The real question is not …, but …
    • If … is to change, … will have to …
    • What is needed above all is …

    A conclusion adds nothing new

    New arguments in the final paragraph read as poor planning. Sum up, take your position, stop. One or two sentences of outlook are welcome, a fresh argument is not.

    Mediation: phrases that carry the source

    Naming the source Explaining what a reader will not know
    • According to an article published in … on …, …
    • The article, which appeared in …, reports that …
    • As … explains in …, …
    • … , a German school-leaving qualification comparable to …
    • … , which in Germany means …
    • In Germany, … is organized by …
    • Unlike in the UK, …

    Cultural explanation is a marked category in mediation. A German institution dropped into an English text without a gloss loses content marks.
