# How to write a discussion essay

!!! tip "At a glance"

    |   |   |
    |---|---|
    | **Purpose** | Weigh **both sides** of an issue and reach a reasoned verdict |
    | **Structure** | Introduction → arguments for and against → conclusion with your position |
    | **Register & voice** | Neutral to formal, mostly neutral perspective, first person in the conclusion, simple present |
    | **Length** | As set by the task, typically 300 to 400 words |
    | **Watch out** | Your own opinion belongs in the **conclusion**, not earlier. Within each side: weakest argument first, strongest last |

**Operators for this task type:**

| Operator | Example task |
|---|---|
| **discuss** — most common, remember this one | *Should schools provide moral guidance? Discuss.* (Abitur 2008) |
| **assess** | *Assess the effectiveness of what authorities can do to change people's behaviour in order to deal with the problems of climate change.* (Abitur 2023) |
| **evaluate** | *Explain the concept of 'Britishness' by evaluating the validity of at least two of the given statements about the United Kingdom.* (Abitur 2007) |

See [Operators](../language/operators.md#writing).

## Step by step

1. **Outline first.** List the main pro and contra points before writing a single sentence. Pick the two or three strongest on each side.
2. **Write the introduction.** Present the issue, give the background a reader needs, and define terms you will use. A one-sentence preview of how the essay is organized helps the reader follow you.
3. **Write the body.** Two workable patterns:

    - **Block pattern:** all arguments for one side, then all arguments for the other.
    - **Ping-pong pattern:** point by point, each argument directly followed by its counterpart.

    Choose one and stay with it. In both patterns, move from the weakest argument to the strongest.

4. **Support every argument.** Claim → reason → example. An argument without support is just an assertion.
5. **Conclude with a verdict.** Weigh the two sides against each other and state which one convinces you more, and why. This is the only place for your opinion.

## Useful phrases

| Purpose | Phrases |
|---|---|
| Introducing the issue | <ul><li>The question of whether … has been widely debated.</li><li>… is a controversial issue because …</li><li>Opinions on … differ sharply.</li></ul> |
| One side | <ul><li>Supporters argue that …</li><li>The strongest argument in favour is …</li><li>Those in favour point to …</li></ul> |
| The other side | <ul><li>Opponents point out that …</li><li>On the other hand, …</li><li>However, it can be argued that …</li><li>A serious objection is that …</li></ul> |
| Weighing up | <ul><li>Weighing the arguments, …</li><li>While … is a valid point, … carries more weight because …</li><li>The two are not of equal weight: …</li></ul> |
| Concluding | <ul><li>On balance, I come to the conclusion that …</li><li>Taking both sides into account, …</li><li>The more convincing case is that …</li></ul> |

## Checklist for a discussion essay

- [ ] Both sides represented with supported arguments?
- [ ] One clear pattern (block or ping-pong) throughout?
- [ ] Arguments ordered weakest to strongest?
- [ ] Opinion only in the conclusion?
- [ ] Conclusion actually weighs the sides instead of just repeating them?

## Common mistakes

- Presenting one side so weakly that the "discussion" is really a comment
- Revealing your opinion in the introduction
- Jumping between the block and ping-pong patterns
- A conclusion that says "both sides have good points" without a verdict
