# Written text types

Every open task names a text type, and the text type decides your structure, your [register](register-and-tone.md) and your perspective before you write a single sentence. This is the quick lookup for everything you **write**.

!!! tip "At a glance"

    |   |   |
    |---|---|
    | **Purpose** | Find the conventions of a written text type a task asks you to produce |
    | **Structure** | One block per text type, always the same five lines |
    | **Register & voice** | Every block names both, because markers check both |
    | **Length** | Where a task gives no word count, use the figures here as a default |
    | **Watch out** | The task always beats this page. If it names a register or an addressee, that wins |

The five lines below mean the same thing on every page of this handbook:

- **Purpose** — what the text is supposed to do to its reader or listener
- **Structure** — the skeleton a marker expects to find
- **Register & voice** — formality, grammatical person, tense
- **Length** — a workable default when the task is silent
- **Watch out** — the mistake that costs most marks in this particular type

### Argumentative text, comment, essay

|   |   |
|---|---|
| **Purpose** | Convince a reader of a position, having shown that you know the other side exists |
| **Structure** | Introductory sentence → arguments with examples → conclusion. Order the arguments deliberately: antithetical, progressive, or problem to solution |
| **Register & voice** | Neutral to formal. Neutral or first person. Simple present |
| **Length** | 200 to 350 words |
| **Watch out** | An argument without an example is an assertion. Paragraphs need [topic sentences](paragraph-structure.md), and stylistic devices should work on the reader, not decorate the page |

### Article

|   |   |
|---|---|
| **Purpose** | Inform a defined readership about a subject and hold their attention while doing it |
| **Structure** | Attention-grabbing headline → introduction → main part in paragraphs → conclusion |
| **Register & voice** | Depends on the publication named in the task: informal for a school magazine, formal for a broadsheet. Neutral or first person. Present tense for the state of things, past for events |
| **Length** | 250 to 400 words |
| **Watch out** | Write the headline last and make it specific. Reported speech where you refer to what others said |

### Blog post

|   |   |
|---|---|
| **Purpose** | Share a personal take on a topic and invite a response |
| **Structure** | Short, pointed headline → lead paragraph that explains why to read on → short paragraphs, ideally with subheadings → conclusion that answers the headline and may call for action → date |
| **Register & voice** | Informal to neutral, matched to the target group. First person. Simple present |
| **Length** | 250 to 350 words |
| **Watch out** | Put the most interesting element in the first paragraph, not the last. A blog post that reads like an essay has missed the type |

### Diary entry

|   |   |
|---|---|
| **Purpose** | Record a moment and what it did to the writer, from inside their head |
| **Structure** | Date → the event → thoughts, worries and feelings about it → an open ending or a resolution |
| **Register & voice** | Neutral to informal. First person. Past tense for the events, present for the reflection |
| **Length** | 150 to 250 words |
| **Watch out** | **Only what the character could plausibly know.** No narrator knowledge, no information from later in the text. Short, sometimes elliptical sentences, exclamations and questions are right here |

### Email or letter, formal

|   |   |
|---|---|
| **Purpose** | Achieve something specific from an institution or a stranger: information, a decision, a correction |
| **Structure** | (Addresses) → date → subject line or reference → salutation → short opening naming your reason for writing → main part → closing request or question → complimentary close → full name |
| **Register & voice** | Formal throughout. First person. Present tense, future for what you expect |
| **Length** | 200 to 300 words |
| **Watch out** | *Dear Sir or Madam* pairs with *Yours faithfully*, *Dear Mr/Ms X* with *Yours sincerely*. No contractions, no slang. Accuracy is judged more strictly here than anywhere else |

### Email or letter, informal

|   |   |
|---|---|
| **Purpose** | Keep in touch with someone you know and tell them something that matters to you |
| **Structure** | Salutation → main part → closing → first name |
| **Register & voice** | Neutral to informal. First person. Contractions and phrasal verbs are welcome |
| **Length** | 150 to 250 words |
| **Watch out** | Informal is not careless. Feelings and exclamations belong here, spelling mistakes do not |

### Letter to the editor

|   |   |
|---|---|
| **Purpose** | React publicly to a published article and put your own position against it |
| **Structure** | Salutation → name the article and summarize the position you are answering → discuss it → state your own view → closing remarks → complimentary close → full name |
| **Register & voice** | Neutral to formal. First person. Simple present |
| **Length** | 200 to 300 words |
| **Watch out** | The reference to the original article belongs in the first two sentences. Readers of the paper have not necessarily read it |

### Letter of application, personal statement

|   |   |
|---|---|
| **Purpose** | Get an interview or a place by matching your qualities to a specific position |
| **Structure** | Your address and theirs → date → subject line → salutation → the post and where you saw it → why you are interested → the skills that make you suitable, with evidence → what you know about the organization → request for an interview → mention of enclosures → close → full name |
| **Register & voice** | Neutral to formal. First person. Present perfect for what you have done, present for what you can do |
| **Length** | One page, no more |
| **Watch out** | Claims without evidence are worthless. Every skill you name should point to something you have actually done |

### Outline

|   |   |
|---|---|
| **Purpose** | Set out the relevant information from a text in a compact, ordered form |
| **Structure** | Introductory sentence with text type, title, author, source, date and topic → the key information in a logical order |
| **Register & voice** | Neutral. Neutral point of view. Simple present, reported speech where needed |
| **Length** | Shorter than a summary, driven by what the task calls relevant |
| **Watch out** | Outline, summarize and sum up are one operator: a concise account of the main points as the task specifies. Select by the task and abstract, do not retell. No opinion |

### Report

|   |   |
|---|---|
| **Purpose** | Give an accurate, impersonal account of an event to someone who was not there |
| **Structure** | Summarizing opening sentence → the events in chronological order → outcome |
| **Register & voice** | Neutral to formal. Neutral perspective. **Past tenses.** Passive and reported speech where they fit |
| **Length** | 200 to 300 words |
| **Watch out** | No thoughts, no feelings, no opinions. If the event is fictional, invent the missing names, places and dates rather than leaving gaps |

### Review

|   |   |
|---|---|
| **Purpose** | Help a reader decide whether a book, film or play is worth their time |
| **Structure** | Introduction with title, author or director, year and genre → outline of the plot without the ending → discussion of beginning, plot development, characters, setting → recommendation |
| **Register & voice** | Neutral to informal, depending on the publication. First person for the judgement. Simple present |
| **Length** | 250 to 350 words |
| **Watch out** | **Never give away the ending.** A recommendation without reasons is not a review, it is a rating |

### Summary

|   |   |
|---|---|
| **Purpose** | Let a reader who does not know the text understand what it says |
| **Structure** | Introductory sentence with text type, title, author, source, date and topic → key statements in a logical order → optional closing sentence |
| **Register & voice** | Neutral to formal. Neutral point of view. **Simple present.** Reported speech where needed |
| **Length** | As set by the task. Class rule of thumb: about one third of the original |
| **Watch out** | Own words throughout. Class rule of thumb: no more than four consecutive words from the source. No examples, no quotations, no opinion. Full page: [How to write an outline or summary](../writing/summary.md) |

### Mediation

|   |   |
|---|---|
| **Purpose** | Give an English-speaking addressee exactly the content from a German source that they need for a stated purpose |
| **Structure** | The structure of the text type the task demands, not the structure of the source |
| **Register & voice** | Set by addressee and text type. Name the source early. Perspective as the task defines it |
| **Length** | About one quarter of the source. In the final examination the source is at most 650 words |
| **Watch out** | Relevance is decided by the **task**, not by the text. No word-for-word translation, no German sentence patterns, no additions of your own. Full page: [How to write a mediation](../writing/mediation.md) |

## The pattern behind all of them

Every one of these blocks answers the same five questions, and every marking scheme asks them in the same order. When a task names a text type you have never practised, work through the five lines yourself:

- [ ] What is this text supposed to **do** to its reader?
- [ ] What **skeleton** does a reader of this type expect?
- [ ] What **register**, what **person**, what **tense**?
- [ ] How **long**, and does the task say?
- [ ] What is the one thing that would make this text **fail its type**?

Answer those and you have a plan, whatever the type.
